# Plan templates

Copy into `.cursor/plans/<slug>/` when starting a slice.

| File | Use |
|------|-----|
| [discovery-brief.md](discovery-brief.md) | Body for `docs/discovery/<slug>/brief.md` |
| [story.md](story.md) | `docs/stories/<slug>/story-0N.md` |
| [handoff-card.md](handoff-card.md) | `*-handoff/*.md` |
| [learnings.md](learnings.md) | Append-only session notes |

Layout per slug:

```
.cursor/plans/<slug>/
  learnings.md
  discover-handoff/
  plan-handoff/
  solve-handoff/
  build-handoff/
```
